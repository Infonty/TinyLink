# TinyURL – URL Shortener

A simple URL shortener service that converts long URLs into short, shareable links.

## Features
- Shorten any valid URL  
- Redirect from short → long URL  
- Auto-generate unique short codes  
- Lightweight REST API  

## Tech Stack
- Node.js / Express  
- MongoDB (or any database)  

## Installation
```bash
git clone https://github.com/your-username/tinyurl.git
cd tinyurl
npm install
